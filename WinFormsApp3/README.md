# RustAdmin: RUSTWIN (ExperimentalWeb)

Веб-приложение для управления сервером Rust через RCON (Remote Console) в стиле RustAdmin.

## Возможности

- **Современный интерфейс** в стиле RustAdmin с темной темой
- **WebSocket RCON** подключение к серверу Rust
- **Многофункциональные вкладки:**
  - Console - просмотр логов сервера с цветовой подсветкой
  - Players - управление игроками
  - Bans - управление банами
  - Statistics - статистика сервера
- **Боковая панель** с настройками:
  - Scheduled commands - запланированные команды
  - Triggered commands - команды по триггерам
  - Highlight system - система подсветки сообщений
  - Console filters - фильтры консоли
- **Двойной ввод:**
  - Chat messages - отправка сообщений в чат
  - Console commands - выполнение команд консоли
- **Цветовая подсветка логов** для разных типов событий
- **История команд** с навигацией стрелками
- **Статус-бар** с информацией о подключении и игроках

## Требования

- .NET 8.0 или выше
- Windows Forms
- Сервер Rust с включенным RCON

## Установка и запуск

1. Убедитесь, что у вас установлен .NET 8.0 SDK
2. Клонируйте репозиторий или скачайте проект
3. Откройте проект в Visual Studio или используйте командную строку:
   ```bash
   dotnet restore
   dotnet build
   dotnet run
   ```

## Настройка сервера Rust

Для использования RCON необходимо настроить сервер Rust:

1. В файле конфигурации сервера (server.cfg) добавьте:
   ```
   rcon.web 1
   rcon.password "ваш_пароль"
   rcon.port 28016
   ```

2. Перезапустите сервер

## Использование

### Подключение к серверу

1. Выберите **Server → Connect** в меню
2. Введите IP-адрес сервера (по умолчанию: 127.0.0.1)
3. Введите порт RCON (по умолчанию: 28016)
4. Введите пароль RCON
5. Нажмите **Connect**

### Интерфейс

#### Вкладка Console
- **Основная область** - логи сервера с цветовой подсветкой
- **Поиск логов** - фильтрация сообщений
- **Clear all** - очистка всех логов

#### Вкладка Players
- Список всех подключенных игроков
- Информация: имя, Steam ID, IP-адрес, время подключения

#### Вкладка Bans
- Список забаненных игроков
- Информация: имя, Steam ID, причина, дата бана

#### Вкладка Statistics
- Статистика сервера
- Информация о производительности

### Отправка команд и сообщений

#### Chat Messages
1. Введите сообщение в поле **"Type a chat message"**
2. Нажмите **Enter** для отправки

#### Console Commands
1. Введите команду в поле **"Type a command to execute"**
2. Нажмите **Enter** или кнопку **Send**

### Навигация по истории команд

- **Стрелка вверх** - предыдущая команда
- **Стрелка вниз** - следующая команда

### Quick Commands

Используйте выпадающий список **"Quick commands"** в статус-баре для быстрого доступа к популярным командам.

### Цветовая подсветка логов

- **Синий** - сообщения чата
- **Красный** - ошибки
- **Оранжевый** - предупреждения
- **Зеленый** - подключения игроков
- **Коралловый** - отключения игроков
- **Белый** - обычные сообщения

## Популярные команды Rust

### Управление игроками
- `players` - список всех игроков
- `kick "имя"` - кикнуть игрока
- `ban "имя"` - забанить игрока
- `unban "имя"` - разбанить игрока
- `mute "имя"` - заглушить игрока
- `unmute "имя"` - разглушить игрока

### Управление сервером
- `status` - статус сервера
- `save` - сохранить мир
- `quit` - выключить сервер
- `restart` - перезапустить сервер
- `shutdown` - выключить сервер

### Чат
- `say "сообщение"` - отправить сообщение всем
- `sayto "имя" "сообщение"` - отправить сообщение конкретному игроку

### Информация
- `serverinfo` - информация о сервере
- `version` - версия сервера
- `uptime` - время работы сервера

## Устранение неполадок

### Не удается подключиться
- Проверьте правильность IP-адреса и порта
- Убедитесь, что RCON включен на сервере
- Проверьте правильность пароля
- Убедитесь, что сервер запущен

### Команды не выполняются
- Убедитесь, что вы подключены к серверу
- Проверьте синтаксис команды
- Некоторые команды могут требовать права администратора

## Технические детали

Приложение использует WebSocket для подключения к RCON серверу Rust. Протокол основан на JSON-сообщениях с идентификаторами запросов.
